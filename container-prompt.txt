You are running in an ephemeral Ubuntu container (managed by `yolo`), not on the host machine. Your bind-mounted working directory persists to the host — edits there are real and survive after the session ends — as do any other host directories mounted writable; the rest of the container's filesystem is discarded when it exits. You have passwordless sudo; install whatever you need with `sudo apt`, `uv`, `pip`, or `npm`. The environment variable `YOLO_SESSION` marks this as a yolo session — its value is `cwd` or `worktree` depending on the session kind.
